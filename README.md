# 盏 ZHAN · 家庭调酒 App — 设计交付（定稿版）

「盏」是一款面向家庭场景的调酒 App：用户录入手边的酒与配料形成「酒库」，App 据此推荐当下能做的配方，并提供分步制作引导、酒款/配料管理与社区分享。Slogan：**一盏好调酒，在家就能做**。

仓库分三块：**定稿原型图（v7）、定稿图标资产（v12）、定稿可点击稿（app/）**。早期版本（`mockups/v1`–`v6`、`icons-3d/v1`–`v10`）一律为**历史迭代留档**，不作为交付口径。全部为设计/演示用途，不含后端与真实业务逻辑。

### v12 三条硬约束（实现时必须遵守）

1. **多倍率素材禁止由大图缩放**：24 / 48 / 72 px（1x / 2x / 3x）由渲染器逐档出图，界面用 `srcset` 取档、`src` 指 1x 兜底；详情页等级卡的 32pt 钻石另取 `5x`（120px 宽、120×144）档——32pt 在 3x 下需 96px，该档足够且不下采样。不得把 1024 缩成 24，也不得回退旧的单张 24px 图。
2. **宝石本体不加任何外描边**：1px 双极性描边已废弃，立体感只靠面明暗与棱线切面，CSS 不再叠加 `drop-shadow` 假描边。
3. **无边钻必须放在实底托板上**：默认 `rgba(12,13,17,.84)` + 12px 圆角；深色底（含 `#17181C` 内容层）必须提到 `rgba(0,0,0,.94)`，或加 1px 内侧高光——`.84` 叠在 `#17181C` 上只有 1.08:1，托板会消失。

### 配方详情页等级卡（019 G1）

三张统计卡顺序为 **用时 / 等级 / 口碑**（等级卡居中），宽度 **120 / 84 / 120**、卡间距 **12**；等级卡左右内边距 **8**，卡内左侧上方为 `Lx` 等级标识、右侧为**一颗 32pt 风味钻石**（V3：上下留白相等、垂直居中；水平靠右，距卡右缘 12）。整页只出现这一颗钻石，标题区不再重复。

- 32pt 显示取 `5x`（120×144）档，素材为**无轮廓线版本**；`1x/2x/3x` 也不带外描边。
- 三种布局可通过 `app/index.html?gem=v1|v2|v3` 对照：v1 = 24pt、整卡居中；v2 = 28pt、底边与另两卡数值行对齐；v3 = 32pt、整卡垂直居中（上下等距）。**交付取 v3**，v1 / v2 只作对比留档。

## 如何打开

- 定稿可点击稿：双击 `app/index.html`，左侧栏为页面导航，筛选弹层、配方跳转、评论、设置等均可交互；页面内可跳转到 `app/levels/levels.html`。配方详情页（019 G1）的等级卡钻石可用 `app/index.html?gem=v1|v2|v3` 切换三版对照。
- 定稿原型图：先看 `mockups/v7/overview.png`（24 页总览），单页在 `mockups/v7/shots/`。
- 定稿图标：`icons-3d/v12/icons/1024/` 为 1024 大图，`1x/2x/3x` 为 24/48/72 三档；先看 `plate-matrix-v12.png` 与 `stroke-ab-v12.png` 理解托板与描边规则。
- 历史静态稿：`mockups/<版本>/index.html` 为对应版本渲染页；3D 动效见 `icons-3d/v10/rotating-icons-v10.html` 与 `icons-3d/v1`–`v5` 的 `rotating-icons.html`（内联 three.js，离线可运行）。

> 无需 npm、无需服务，`file://` 直接打开即可。

## 图片 / 动效的对照方式

- **v7 定稿原型**：`shots/001-L1-年龄确认.png` 这类文件名 = 「序号-页面编码-页面名」，序号即交付顺序；页面清单见 `mockups/v7/README.md`。019 配方详情页另含 `019-G1-配方详情-v1/v2/v3.png`（等级卡三版）与 `019-G1-等级卡-三版对比-v1-v2-v3.png`（并排对比）。
- **v12 定稿图标**：`icons/<倍率>/flavor_r1..r9.png`，r1–r9 与配方一一对应（r1 青柠硬糖 / r2 蜜桃气泡 / r3 陈年威士忌 / r4 西柚苏打 / r5 梅子糖浆 / r6 威士忌酸 / r7 三味均衡 / r8 极限全高 / r9 海盐青柠）；`plate-matrix-v12.png` 为「4 种底色 × 有/无托板」矩阵，`stroke-ab-v12.png` 为有/无描边对比。
- **历史静态稿**：PNG 命名 = 页面编码，`H1/H1b` 首页、`H2` 筛选、`H3` 搜索，`C1`–`C6` 酒库，`G1`–`G3` 配方与制作，`S1`–`S4` 社区，`M1`–`M3` 我的，`L1`–`L3b` 登录引导；与 `render.js` 的 `window.__ZhanFrames__` 顺序一致。
- **历史 3D 图标**：`L1.png`–`L5.png` 大图预览，`L1@24.png`–`L5@24.png` 为 24px 实际尺寸，`levels-overview.png` / `in-app-usage.png` 为总览与应用示意，`compare-*.png` 为版本对比。
- 本仓库**没有 GIF**；动效以 `rotating-icons-v10.html` 的实时渲染为准，静态帧以各版本 PNG 为准。

## 已知限制

1. `mockups/` 下全部是**静态截图**，不可点击；交互行为以 `app/` 为准。
2. `app/` 是前端演示稿：数据硬编码在 `app.js` / `v7.js`，刷新即重置；无后端、无账号体系。覆盖 `home / search / bottle / bottle-detail / recipe / flow / chat / comment / me / settings` 10 个路由，PRD 中的电商（美团闪购）、UGC 发布、扫码入库等能力均未接入。
3. **v12 在 24px 下四维轮廓不可辨**，只剩色相与明度可读；无描边后，24px 可读性**完全依赖托板**。
4. **v12 直贴照片或白底不可行**：照片底体色对比实测仅 1.01–1.44，无托板直贴白底也只有 2.83:1；深色底用 `.84` 托板仅 1.08:1，必须 `.94` 或 1px 内侧高光，换底图需回归。
5. **v12 的折射与切面细节依赖底片内容**，纯色背景下钻石会「化开」；静态 PNG 无动画。
6. **v12 成品钻只有 9 颗**：配方多于 9 条时按四维就近复用，长列表会出现可感知的重复，需在数据里标记复用来源。
7. `icons-3d/v10` 及其更早版本为历史迭代：v10 曾被标为定稿，但存在「24px 轮廓不可辨 + 靠外描边兜底」的取舍，v12 已用托板方案取代；旧版本限制仍保留在其目录中的图里。
8. `icons-3d/v7` 渲染未完成未收录；各版本 `_src`、v11 的 `_ref-with-stroke`（带边参考）等构建/参考脚手架未收录，**无法从本仓库直接重跑渲染**。
9. `mockups/*/screenshot.js` 写死了原机器的 Chrome 与 puppeteer 绝对路径，复跑需改路径并装依赖。
10. `assets/` 图片来自 Unsplash（见 `mockups/hifi/dl.sh`），仅作设计演示，商用需另行授权。
11. `mockups/v7/app/` 是出图时的快照，其中等级页链接指向归档内不存在的 `../levels`；**生效的等级页在仓库根 `app/levels/`**。
12. PRD 内部分字段仍为占位（作者栏、部分评审日期标 `[TBD]`）。
