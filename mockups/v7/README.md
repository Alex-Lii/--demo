## 跨页数据基线

- 配方 8 款、酒 4 瓶、材料 5 种、可做 **7 杯**（含 2 杯 DIY）、收藏 **8 杯**、历史 **8 杯**。
- 用户统一为「杯中物」（M1 / S1 / S2 / S3 同一头像 `a3.jpg`）。
- 酒价：绝对伏特加 ¥99、百加得白朗姆 ¥89、尊尼获加黑牌 ¥229、孟买蓝宝石金酒 ¥135。
- 配方钻石 / 阶名固定：大都会 r7·二阶、螺丝刀 r2·一阶、金菲士 r1·二阶、威士忌酸 r6·二阶、荔枝马天尼 r8·三阶、西柚帕洛玛 r4·一阶、自由古巴 r5·一阶、莫吉托 r9·二阶。

## 占位与素材说明

- 可选酒瓶照只有 `b02 / b03 / b05 / b07` 四张；C3 中「必富达金酒 / 唐胡里奥 / 金宾」没有实拍，使用瓶形图标占位。
- L3b 的「哈瓦那俱乐部 3 年」无实拍，使用瓶形图标占位。
- 材料实拍仅 `i01–i05`（柠檬 / 柑橘 / 甜橙 / 草莓 / 西瓜），没有糖浆、饮品、香料图，故 C5 只列 5 种水果，未虚构其他分类内容。
- L3 家族缩略图复用现有酒款 / 调酒照片（伏特加、朗姆、威士忌、金酒、龙舌兰、利口酒），非家族专属图。
- 部分酒款照片与配方名的语义不完全对应（沿用的 v6 素材），本轮未替换图片，仅保证同一配方跨页的钻石、阶名、价格、用户名一致。
